# MyBody2.0

Personalised body transformation PWA for nutrition, workouts, activity, measurements, progress tracking, and multi-user profiles.

## Current app
- iPhone-friendly responsive dashboard
- Multi-user device-local login and separate user data
- Personalised onboarding and plan generation
- Current weight, goal weight and progress tracking
- Workout planning, target weights, actual sets/reps and history
- Nutrition targets, meal logging, food database and history
- Dark/light mode
- LocalStorage persistence
- Service worker offline caching
- PWA manifest and custom MYBODY 2.0 icon
- GitHub Pages deployment with live build-number badge

## Product name
**MyBody2.0**

## Run locally
Serve the repository with any static HTTP server. Opening `index.html` directly will show the UI, but service-worker installation requires HTTP/HTTPS.

All health and fitness values are estimates and should not be treated as medical advice.
